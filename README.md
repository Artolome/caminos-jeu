# Caminos — Carnet des rencontres

[Jouer à Caminos](https://artolome.github.io/caminos-jeu/)

Un voyage illustré à la première personne pour apprendre l’espagnol, niveau A1–A2 : 28 rencontres, trois fins et des personnages animés aux styles distincts.

## Jouer

Maintenir la flèche ↑, W, Z, Espace ou le bouton à l’écran pour avancer. Continuer les dialogues avec Entrée et choisir avec les touches 1, 2, 3 ou les boutons.

Au début du voyage, Sancho a besoin d’aide : Rucio a soif. Prendre la gourde, la remplir à la fontaine et donner à boire à l’âne. Les dessins sont cliquables ; les touches 1, 2, 3 et les boutons tactiles permettent aussi d’agir. Rucio boit dans son abreuvoir et cinq expressions rejoignent le carnet.

À la Casa Azul, retrouver les pinceaux et les couleurs rouge, bleue et jaune de Frida dans n’importe quel ordre. Avec tout le matériel, activer le chevalet : Frida peint et les fleurs apparaissent sur la toile. Utiliser les dessins, les touches 1 à 5 ou les boutons tactiles. Cinq nouveaux mots rejoignent le carnet.

[Commencer un nouveau voyage directement chez Frida](https://artolome.github.io/caminos-jeu/#frida_kahlo)

Les missions proposent des indices, une traduction et un mode adapté à la préférence de mouvements réduits du navigateur. Les sauvegardes restent dans le navigateur, y compris les objets trouvés. Three.js et les polices sont chargés en ligne.

## Publication

Ce dépôt contient uniquement la version jouable destinée à GitHub Pages. La publication utilise la branche `main`, dossier racine. `index.html` intègre les illustrations du jeu ; `.nojekyll` permet de le servir sans transformation.
